02 Parameter

Parameter dikirim sebagai query string. Semua parameter opsional kecuali pesan (jika kosong, memakai teks default).

ParameterTipeDefaultKeterangan
pesan WAJIB* string see u, hopefully… Isi bubble chat. Maks 1000 karakter. Mendukung emoji (otomatis jadi emoji Apple) & baris baru (%0A → baris baru). Karakter berbahaya otomatis di-escape (aman XSS).
mode light | dark light dark = dark mode ala IG (UI gelap + wallpaper percakapan gelap). light memaksa mode terang.
seed integer acak Kunci wallpaper & level baterai (30–100%). Seed sama → hasil identik (deterministik). Tanpa seed, tiap request menghasilkan wallpaper berbeda.
html 1 | true 0 1 = kembalikan halaman HTML interaktif, bukan JPG.
ℹ️* Secara teknis pesan boleh dikosongkan — server memakai teks default "see u, hopefully we will meet in the next life."

cURL

bash 
# simpan hasil JPG ke file
curl -o hasil.jpg "https://DOMAIN/iqc?pesan=halo%E2%9D%A4&mode=dark"

# wallpaper terkunci (seed) — hasil selalu identik
curl -o fix.jpg "https://DOMAIN/iqc?pesan=hai&seed=42"

Node.js (fetch)

node 
// pesan otomatis di-encode oleh URLSearchParams (emoji aman)
const params = new URLSearchParams({ pesan: 'halo❤', mode: 'dark' });
const res = await fetch(`https://DOMAIN/iqc?${params}`);

const ct = res.headers.get('content-type');
if (!ct?.startsWith('image/')) throw new Error('render gagal (coba ulang)');

const buffer = Buffer.from(await res.arrayBuffer());
// buffer = JPEG siap dikirim

04 Respons & Error

KasusStatusContent-TypeIsi
Sukses (default)200image/jpegFoto kartu 1350×2400
Dengan html=1200text/htmlHalaman interaktif
Render gagal (jarang)200text/htmlHalaman fallback — link tetap bisa dibuka, bot tinggal mendeteksi content-type
Server error500text/plainPesan kesalahan singkat
🌙Cold start: request pertama setelah idle bisa memakan 3–10 detik (Chromium harus di-init). Request berikutnya jauh lebih cepat. Untuk bot, disarankan retry 1–2x ketika respons bukan image/*.
🔒Cache: tanpa seed, respons Cache-Control: no-store (tiap request wallpaper baru). Dengan seed, hasil deterministik sehingga aman di-cache CDN/client.

05 Batasan & Catatan

  • Pesan maksimal 1000 karakter; karakter kontrol dibuang otomatis.
  • Emoji dirender gaya Apple/iPhone di semua perangkat — emoji umum (❤️😂🔥💯🙏 dll.) tertanam di server; emoji lain dimuat dari CDN saat render, dengan fallback ke teks bila CDN gagal.
  • Wallpaper = percakapan tiruan (bubble, emoji, foto, voice note, avatar, "Dilihat") yang diburamkan — acak setiap request, kecuali seed diberikan.
  • Jam status bar otomatis WIB (Asia/Jakarta), format HH.MM, update tiap detik pada mode interaktif.
  • Baterai status bar acak 30–100% (mengikuti seed).
  • Teks pesan di-escape server-side — aman dari XSS; jangan khawatir menyisipkan karakter spesial.
  • Ukuran & kualitas hasil: 1350×2400 px, JPEG quality 92 (~150–250 KB).
